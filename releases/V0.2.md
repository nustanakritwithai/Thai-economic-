# V0.2 Core Data Connectors — Release Contract

**Status:** ACTIVE — PLANNING

## Mission
Implement a small, reliable set of official public-data connectors that prove end-to-end ingestion behavior before expanding coverage.

## Priority sources
P0:
1. BOT
2. NESDC
3. TPSO CPI/PPI
4. MOF
5. Customs

Selected NSO datasets may be included only if they do not delay the P0 gate.

## In scope
- Source-specific retrieval clients
- Raw source snapshot preservation
- Retrieved-at timestamps
- Checksums
- Idempotent reruns
- Minimal parser output aligned to V0.1 Data Contract
- Connector error classification
- Retry/backoff rules
- Source health reporting
- Fixtures/tests for each implemented source
- End-to-end evidence for a small set of high-value series

## Out of scope
- Broad ingestion of every available dataset
- Full normalization/validation engine (V0.3)
- Production economic database deployment (V0.4)
- Forecasting
- Multi-Agent runtime
- Policy analysis

## Gate
- [ ] BOT connector proves retrieval + raw preservation
- [ ] NESDC connector proves retrieval + raw preservation
- [ ] TPSO connector proves retrieval + raw preservation
- [ ] MOF connector proves retrieval + raw preservation
- [ ] Customs connector proves retrieval + raw preservation
- [ ] Rerunning a connector does not create unintended duplicates
- [ ] Every retrieval produces source ID, retrieved_at, checksum, parser version
- [ ] Failure of one connector does not crash unrelated connectors
- [ ] Fixtures/tests cover successful and failed retrieval behavior
- [ ] CI passes
- [ ] V0.2 verification snapshot committed

UNKNOWN ≠ PASS.

## First task
Inventory exact official endpoints/files for each P0 source and select the minimum high-value series required for connector proof. Do not implement all data at once.
