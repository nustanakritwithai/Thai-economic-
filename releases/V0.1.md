# V0.1 Foundation — Release Contract

**Status:** ACTIVE

## Mission
Create the stable foundation required to ingest public economic data and later support models and multi-agent analysis without redesigning core identity, vintage, authority, and audit semantics.

## In scope
- Repository topology
- PM Control
- GitHub Pages PM dashboard
- Architecture baseline
- Economic Data Contract
- Core schemas
- Source Registry
- Audit and ID conventions
- Agent Governance baseline
- Decision/Risk/Parking Lot/Recovery documents
- CI validation baseline
- V0.1 verification report and final snapshot

## Explicitly out of scope
- Production BOT/NESDC/TPSO/MOF/Customs connectors
- Economic database deployment
- GDP/CPI forecasts
- Economic State scoring
- Multi-Agent runtime
- Policy simulation
- National Digital Twin

## Definition of Done
- [ ] Required repository structure exists
- [ ] PM Control identifies V0.1 as sole active version
- [ ] Pages dashboard reflects active version and gate
- [ ] Architecture authority boundaries documented
- [ ] Data Contract defines Source/Series/Observation/Vintage semantics
- [ ] Core JSON schemas are machine-valid
- [ ] Source Registry covers P0/P1 sources
- [ ] Audit IDs and lineage conventions documented
- [ ] Agent Governance baseline documented
- [ ] Recovery Protocol documented
- [ ] CI validates repository baseline
- [ ] Verification evidence records PASS/FAIL for every item
- [ ] Final release snapshot records commit SHA and known limitations
