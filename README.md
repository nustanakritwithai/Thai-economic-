# Thailand Economic OS

> Public-data economic intelligence infrastructure for Thailand.

## Active version
**V0.2 Core Data Connectors — ACTIVE**

## North Star
**Digital Economic Twin of Thailand + Autonomous AI Economic Organization**

The project is built as a capability chain:

`Data Truth → Economic Measurement → Forecast Intelligence → Multi-Agent Organization → Causal Intelligence → Policy Intelligence → Economic Digital Twin → Autonomous Economic Cabinet → Adaptive Thailand Economic OS`

## Current goal
Prove reliable official public-data acquisition: raw preservation, source identity, timestamps, checksums, parser metadata, idempotent reruns, failure isolation, fixtures, and CI evidence.

## Operating rules
- WIP limit = **1 active version**
- **UNKNOWN ≠ PASS**
- Every substantial task must answer **WHY → WHAT → PROOF → NEXT**
- No future-version work before the current release gate passes
- GitHub is the engineering source of truth
- Economic observations must be traceable to source, release date, vintage, and checksum
- LLMs interpret evidence; they do not create official economic observations
- Every forecast must be recorded before the actual value is known
- Autonomy must never exceed auditability
